# v0.1.0 界面设计文档

> 本版本界面设计目标：做成一个本地 AI 生图工作台，兼顾“可爱主题”和“专业生产力工具”的清晰度，让用户能稳定完成 API 配置、参数选择、文生图/图生图、图片预览和生成记录回看。

---

## 1. 页面结构概览

### 1.1 页面清单

| 页面 | 功能描述 | 优先级 |
|------|----------|--------|
| 主工作台 | 生成窗口选择、生图区、生成参数、提示词输入、图片预览和生成记录 | P0 |
| API 设置弹窗 | 配置 API 地址、认证信息、模型、能力边界状态 | P0 |
| 图片预览弹窗 | 查看生成图或图生图参考图细节 | P0 |
| 主题选择入口 | 在多套视觉主题之间切换 | P1 |

### 1.2 主界面布局

主界面采用横向三栏结构，比例为 1:2:2。顶部保留轻量标题栏和全局操作区，中间为核心工作区。

```text
┌────────────────────────────────────────────────────────────────────────────────────────────┐
│  本地生图工作台                         API: 自定义服务 / model-x   [主题] [API 设置]     │
├──────────────────┬──────────────────────────────────────┬────────────────────────────────┤
│ 左侧生成窗口 1份 │ 中间工作区 2份                       │ 右侧预览与生成记录 2份         │
│                  │                                      │                                │
│  [+ 新增]        │  ┌────────────────────────────────┐  │  ┌──────────┐ ┌──────────┐    │
│  生成窗口 1      │  │                                │  │  │ 预览图 1 │ │ 预览图 2 │    │
│  生成窗口 2      │  │        当前主生图区              │  │  └──────────┘ └──────────┘    │
│  生成窗口 3      │  │        生成图 / 参考图预览       │  │  模型 / 尺寸 / quality         │
│                  │  │                                │  │  状态 / 时间                   │
│                  │  └────────────────────────────────┘  │                                │
│                  │                                      │  ┌──────────┐ ┌──────────┐    │
│                  │  模式 [文生图|图生图]  比例 [16:9]   │  │ 预览图 3 │ │ 预览图 4 │    │
│                  │  分辨率 [1K|2K|4K]    质量 [low..]   │  └──────────┘ └──────────┘    │
│                  │  参考图 [缩略图] [移除]              │                                │
│                  │  ┌────────────────────────────────┐  │                                │
│                  │  │ 输入提示词...                   │  │                                │
│                  │  └────────────────────────────────┘  │                                │
│                  │                              [生成]  │                                │
└──────────────────┴──────────────────────────────────────┴────────────────────────────────┘
```

## 2. 视觉设计原则

### 2.1 工作台优先

- 第一屏直接展示主工作台，不做营销首页。
- 左侧用于生成窗口选择，中间用于当前创作，右侧用于当前窗口的结果回看。
- 工具控件靠近输入区，用户提交前能看到 API、模型、模式、比例、分辨率和 quality。

### 2.2 主题可切换

- 默认推荐先实现 2 套主题：可爱粉色、酷炫黑金。
- 其他配色方案作为后续扩展或主题预设保留。
- 主题只改变颜色、阴影、边框和局部材质感，不改变主流程和控件位置。

### 2.3 专业配色规则

- 使用“角色色”而不是随意铺色：背景、面板、文字、主操作、强调、边框、状态色分开定义。
- 大面积区域以中性色为主，粉色、金色、紫色等强风格色用于按钮、选中态、重点标签和进度状态。
- 文字与背景必须保持足够对比度；小字号文本不得使用低对比浅色。
- 状态色固定语义：成功用绿、警告用黄/橙、错误用红，不用粉色或金色承担错误语义。

## 3. 主题配色方案

### 3.1 方案 A：奶油粉创作室

**气质**：可爱、轻松、适合偏个人创作和视觉灵感场景。  
**建议用途**：默认浅色主题候选。

| 角色 | 颜色 | 用途 |
|------|------|------|
| 背景 | `#FFF7FA` | 应用主背景 |
| 面板 | `#FFFFFF` | 三栏面板、弹窗 |
| 次级面 | `#FFE7EF` | 选中态、参考图区域 |
| 主文字 | `#2D1B23` | 标题、主要内容 |
| 次文字 | `#7B6470` | 元信息、说明 |
| 主色 | `#E94B8A` | 生成按钮、当前选中 |
| 主色 hover | `#C92F6C` | 按钮悬停 |
| 边框 | `#F2C6D5` | 面板分隔、输入框 |
| 辅助色 | `#8BD8BD` | 成功状态、轻提示 |
| 警告 | `#B7791F` | 参数未知、API 未确认 |
| 错误 | `#C8325A` | 请求失败 |

**界面落点**：
- 左侧生成窗口用白色面板，当前窗口用浅粉底。
- 中间生图区保持白色或极浅粉背景，避免影响图片观感。
- 生成按钮使用主粉色，quality、尺寸等选择器使用浅粉选中态。
- 参考图缩略图外框用粉色边框，移除按钮用灰色或红色。

### 3.2 方案 B：曜石黑金控制台

**气质**：酷炫、专业、偏创作者工具和高级控制台。  
**建议用途**：默认深色主题候选。

| 角色 | 颜色 | 用途 |
|------|------|------|
| 背景 | `#0B0B0D` | 应用主背景 |
| 面板 | `#151517` | 三栏面板 |
| 次级面 | `#211D16` | 选中态、参数区 |
| 主文字 | `#F7F1E5` | 标题、主要内容 |
| 次文字 | `#B8AD9C` | 元信息、说明 |
| 主色 | `#D6A84F` | 生成按钮、重点状态 |
| 主色 hover | `#F0C76A` | 按钮悬停、高亮 |
| 边框 | `#3A3326` | 面板分隔、输入框 |
| 冷辅助 | `#46B8C8` | 进行中、信息提示 |
| 成功 | `#52C48D` | 生成成功 |
| 警告 | `#D6A84F` | 参数未知 |
| 错误 | `#F06464` | 请求失败 |

**界面落点**：
- 大背景使用近黑，主生图区使用深灰面板，图片区域增加细金边。
- 生成按钮使用金色，文字用黑色或深棕保证可读。
- 预览区卡片使用低亮度深面板，选中图用金色描边。
- 信息提示和“生成中”使用冷青色，避免所有强调都堆到金色上。

### 3.3 方案 C：云白蓝专业版

**气质**：干净、可靠、接近 SaaS / 工具软件。  
**建议用途**：面向长期使用、参数较多时的稳妥主题。

| 角色 | 颜色 | 用途 |
|------|------|------|
| 背景 | `#F6F8FB` | 应用主背景 |
| 面板 | `#FFFFFF` | 三栏面板、弹窗 |
| 次级面 | `#EEF4FF` | 选中态、提示块 |
| 主文字 | `#172033` | 标题、正文 |
| 次文字 | `#68758A` | 元信息 |
| 主色 | `#2563EB` | 主按钮、链接 |
| 主色 hover | `#1D4ED8` | 按钮悬停 |
| 边框 | `#DCE3EE` | 输入框、分隔 |
| 辅助色 | `#14B8A6` | 成功或辅助强调 |
| 警告 | `#D97706` | 参数未知 |
| 错误 | `#DC2626` | 请求失败 |

**界面落点**：
- 适合默认给不喜欢强风格的用户。
- 参数控件和 API 设置弹窗最清晰。
- 图片预览区可以做成白底缩略图网格，信息层级最稳定。

### 3.4 方案 D：极光紫青创作台

**气质**：有 AI 创作感，但比纯紫渐变更克制。  
**建议用途**：希望有一点未来感，但不牺牲可读性的主题。

| 角色 | 颜色 | 用途 |
|------|------|------|
| 背景 | `#11131A` | 应用主背景 |
| 面板 | `#1A1D27` | 三栏面板 |
| 次级面 | `#24283A` | 参数区、输入区 |
| 主文字 | `#F4F7FB` | 标题、正文 |
| 次文字 | `#A6B0C3` | 元信息 |
| 主色 | `#8B5CF6` | 主按钮、选中态 |
| 主色 hover | `#A78BFA` | 按钮悬停 |
| 边框 | `#30364A` | 分隔、输入框 |
| 辅助色 | `#22D3EE` | 生成中、链接 |
| 成功 | `#34D399` | 生成成功 |
| 警告 | `#FBBF24` | 参数未知 |
| 错误 | `#FB7185` | 请求失败 |

**界面落点**：
- 不使用大面积紫色背景，紫色只给主操作和选中态。
- 生图区保持深中性，避免色偏影响图片判断。
- 右侧预览区可用紫色描边标记当前选中图。

### 3.5 方案 E：石墨粉点缀

**气质**：成熟、克制、带一点柔和个性。  
**建议用途**：粉色主题的专业版替代，不会显得过甜。

| 次级面 | `#EEE8EB` | 参数区、输入区 |
| 主文字 | `#242124` | 标题、正文 |
| 次文字 | `#6F6870` | 元信息 |
| 主色 | `#C74C7A` | 主按钮、选中态 |
| 主色 hover | `#A83D66` | 按钮悬停 |
| 边框 | `#D8CDD3` | 分隔、输入框 |
| 辅助色 | `#4A8F8C` | 成功或辅助强调 |
| 警告 | `#A66A00` | 参数未知 |
| 错误 | `#B4233A` | 请求失败 |

**界面落点**：
- 适合觉得奶油粉太可爱、但仍想保留粉色品牌感的用户。
- 右侧生成记录更像专业资料库，主按钮和选中态保留粉色记忆点。

## 4. 关键区域设计

### 4.1 左侧生成窗口

**内容**：
- 用户提示词摘要
- 当前状态：待生成、生成中、成功、失败
- 模式标签：文生图 / 图生图
- 时间

**交互**：
- 点击生成窗口时，中间生图区和右侧预览切换到该窗口。
- 生成窗口展示最近状态和记录数量。
- 每个窗口条目保持稳定高度，便于扫描和点击。

### 4.2 中间生图区

**内容**：
- 当前生成图片
- 空状态
- 加载状态
- 错误状态
- 图生图参考图预览

**交互**：
- 点击图片打开预览弹窗。
- 图生图模式下，参考图与生成图需要有明确标签。
- 图片区域不使用强色背景，避免影响用户判断图片颜色。

### 4.3 参数与输入区

**控件**：
- 模式：分段控件，文生图 / 图生图。
- 尺寸比例：分段控件，1:1、4:3、3:4、16:9、9:16。
- 分辨率：分段控件，1K、2K、4K。
- quality：分段控件，low、medium、high。
- 参考图：缩略图 + 添加按钮 + 移除按钮。
- 提示词输入：多行输入框。
- 生成：主按钮。

**状态**：
- API 未配置：生成按钮禁用，并提示先配置 API。
- 参数未知：参数旁显示“未确认”状态。
- 正在生成：生成按钮进入加载态。
- 生成失败：保留输入内容，允许用户调整后重试。

### 4.4 右侧预览与生成记录

**内容**：
- 缩略图
- 生成状态
- 生成时间
- 提示词摘要
- 模型
- 比例、分辨率、quality

**布局**：
- 桌面宽度充足时使用双列缩略图网格。
- 每条记录不做厚重卡片嵌套，缩略图和元信息保持紧凑。
- 当前选中图片使用主题主色描边。

## 6. 主题推荐排序

| 排序 | 主题 | 推荐原因 |
|------|------|----------|
| 1 | 奶油粉创作室 | 符合“可爱粉色”的明确诉求，适合作为差异化默认主题 |
| 2 | 曜石黑金控制台 | 符合“酷炫黑金”的明确诉求，适合作为深色主题 |
| 3 | 云白蓝专业版 | 最稳妥，适合长时间生产力使用 |
| 4 | 石墨粉点缀 | 粉色但更专业，可作为奶油粉的成熟替代 |
| 5 | 极光紫青创作台 | 有 AI 创作感，但需要克制使用以免喧宾夺主 |
