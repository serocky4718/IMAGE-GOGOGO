#### 当时发现的问题

### P0 阻塞问题

无。

### P1 重要问题

#### 1. 历史废弃项：明确标记“不支持”的 API 能力没有被拦截

- 问题描述：API 设置里可以把文生图、图生图、比例、分辨率、quality 标记为“不支持”，但提交前不会阻止用户选择这些模式或参数。
- 复现方式 / 触发条件：配置 API 能力为 `unsupported`，回到主界面选择对应模式或参数并生成。
- 预期表现：按当时 QA 口径，禁用对应选项，或提交前给出明确提示“当前 API 不支持该参数”。
- 实际表现：`canGenerate` 只检查 API、提示词、参考图，不检查能力边界；主进程请求也不校验。
- 相关位置：`src/components/PromptComposer.tsx:38`、`electron/main.ts:192`
- 当前状态：该要求已被 2026-05-14 新版产品口径取代，v0.1.0 中能力边界以提示和记录为主，不要求强制阻断。

#### 2. 生图请求没有超时控制，第三方 API 挂起会导致流程卡死

- 问题描述：`fetch(config.endpoint)` 没有 `AbortController` 或超时机制。
- 复现方式 / 触发条件：配置一个长时间不响应的 API 地址后点击生成。
- 预期表现：超过合理时间后失败，记录状态变为 `failed`，并提示网络超时或服务无响应。
- 实际表现：请求可能长期 pending，当前窗口保持生成中，按钮持续禁用。
- 相关位置：`electron/main.ts:213`
- 建议修复方向：增加请求超时、下载图片超时和可理解错误文案；必要时支持取消当前请求。

#### 3. 至少一种第三方 API 的稳定适配尚不明确

- 问题描述：当前适配层固定发送 `mode`、`size`、`aspect_ratio`、`resolution`、`quality`、`image`、`response_format`，并假设返回 `url` 或 `b64_json`。
- 复现方式 / 触发条件：接入字段格式不同的第三方生图 API。
- 预期表现：至少有一个明确、可验证的 API 模板或适配方案能稳定完成生成。
- 实际表现：目前更像“通用 raw POST”，缺少已验证 provider/template 和集成测试。
- 相关位置：`electron/main.ts:200`
- 建议修复方向：明确首版支持的 API 协议，例如 OpenAI-compatible 或自定义模板；补一个 mock API 集成测试覆盖成功、失败、返回格式异常。

#### 4. 本地状态读取失败会静默回退，可能造成配置/记录丢失风险

- 问题描述：读取 `state.json` 出错时直接返回空状态，保存失败也没有 UI 反馈。
- 复现方式 / 触发条件：状态文件损坏、权限异常、磁盘写入失败。
- 预期表现：提示用户配置读取失败，保留或备份损坏文件；保存失败时提示用户。
- 实际表现：`readJsonFile` catch 后直接 fallback，`commit` 未捕获保存失败。
- 相关位置：`electron/main.ts:21`、`src/App.tsx:39`
- 建议修复方向：区分文件不存在和解析失败；解析失败时备份旧文件并提示；保存失败时显示错误状态。

### P2 优化问题

#### 1. 图片预览对“生成图”和“图生图参考图”的区分不足

- 问题描述：预览弹窗只显示“文生图 / 图生图”，没有明确标记当前查看的是生成图还是参考图。
- 复现方式 / 触发条件：图生图记录进入预览。
- 预期表现：明确展示“生成图”或“参考图”。
- 实际表现：弹窗标题和 footer 未区分图片来源。
- 相关位置：`src/components/ImagePreviewDialog.tsx:13`
- 建议修复方向：给预览入口和弹窗增加 image kind 标识。

#### 2. API 地址缺少基础格式校验

- 问题描述：保存配置时只要求非空，不校验 URL 格式。
- 复现方式 / 触发条件：输入无效 API 地址并保存。
- 预期表现：提示 URL 格式不正确。
- 实际表现：可保存，生成时才失败。
- 建议修复方向：保存前校验 `http/https` URL，并在输入框下方显示错误文案。

#### 3. Electron 安全配置仍可收紧

- 问题描述：已开启 `contextIsolation`、关闭 `nodeIntegration`，但 `sandbox` 为 `false`。
- 复现方式 / 触发条件：通用安全审查。
- 预期表现：桌面应用尽量启用 sandbox，并限制 IPC 输入。
- 实际表现：`sandbox: false`。
- 相关位置：`electron/main.ts:48`
- 建议修复方向：评估开启 sandbox；对 IPC 入参做 schema 校验。
