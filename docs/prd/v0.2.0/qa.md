## 边界情况检查

- 空数据：默认 state 和提示词库空状态已覆盖。
- 网络失败：生成失败会落为 `failed` 记录并展示错误。
- 重复点击：生成按钮受 `isGenerating` 限制；提示词保存按钮受 `isSaving` 限制。
- 无权限用户：本地桌面应用暂无账号权限模型，不适用。
- 输入异常值：生成参数在 Electron 主进程有基础校验。
- 页面刷新 / 重启：状态结构支持持久化；建议发布前用旧版真实 `state.json` 再做一次启动验证。
- 移动端显示：桌面 Electron 应用，非核心验收；窄屏仅建议视觉回归。
- 拖拽释放：已监听 window `mouseup`，基本可避免拖拽卡住。
