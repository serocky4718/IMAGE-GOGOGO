## Reviewer 检查重点

- [ ] `normalizeState` 是否兼容 v0.1.0 旧数据。
- [ ] `GenerationThread` 的 composer 是否真正按线程隔离。
- [ ] 切换线程是否不会丢失未生成的提示词草稿。
- [ ] 自动模式是否只由参考图存在与否决定。
- [ ] 提示词库是否持久化到本地状态。
- [ ] 图片预览拖拽事件是否正确结束，避免鼠标释放后仍在拖动。
- [ ] UI 改造是否没有破坏 API 设置、生成记录、图片删除等已有功能。

## QA 验收清单

- [ ] 启动旧版本状态数据，应用不白屏。
- [ ] 新建两个对话，分别输入不同提示词，切换后互不影响。
- [ ] 两个对话分别选择不同参数，切换后参数正确恢复。
- [ ] 对话 A 添加参考图，对话 B 不显示该参考图。
- [ ] 保存提示词后，提示词库出现对应条目。
- [ ] 读取提示词后，只更新当前对话。
- [ ] 重启应用后，提示词库仍存在。
- [ ] 无参考图生成时为文生图。
- [ ] 有参考图生成时为图生图。
- [ ] 比例选项包含 `3:2`、`2:3`、`2:1`。
- [ ] 当前图和生成记录图都可以缩放、拖拽和重置。
- [ ] 主界面显示“Rocky的图片工作室”，不显示原图标。
- [ ] 输入区不再重复显示“当前API”和“参数边界：模式”。
- [ ] `npm run typecheck` 通过。
- [ ] `npm run build` 通过。

## 风险与依赖

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 本地状态结构变化导致旧数据读取失败 | 高 | 在 `normalizeState` 中补齐所有新增字段 |
| 提示词库和对话草稿都写入状态，保存频率增加 | 中 | 复用现有 `commit`，避免额外存储通道 |
| 图片缩放拖拽交互边界复杂 | 中 | 控制缩放范围，关闭弹窗重置状态 |
| UI 美化影响原有流程 | 中 | 先完成功能，再做样式；Reviewer 做回归检查 |

## 交付口径

Builder 完成后需要交付：

- 功能实现说明。
- 修改文件清单。
- 已执行的检查命令和结果。
- 未完成或建议后置的事项。

Reviewer 完成后需要交付：

- 按严重程度排序的问题列表。
- 是否建议进入 QA。

QA 完成后需要交付：

- 通过/失败的验收项。
- 失败项复现步骤。
- 是否建议打包发布。
