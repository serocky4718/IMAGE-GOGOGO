# v0.2.0 发布前手动回归清单

> 这份清单用于 `v0.2.0` 发布前的人工确认。目标是把最关键的桌面端路径再走一遍，确认品牌、迁移、核心生成流程和图片交互都没有回归。

## 一、Electron 启动与基础界面

- [ ] 在开发环境或打包 EXE 中，应用可以正常启动。
- [ ] 启动后直接进入主工作台，没有白屏、报错弹窗或卡死。
- [ ] 窗口最小化、最大化、关闭操作正常。
- [ ] 三栏布局正常，没有明显错位、遮挡或溢出。

## 二、品牌与窗口标题

- [ ] 主界面顶部标题显示为“Rocky的图片工作室”。
- [ ] 顶部不再显示旧的标题图标。
- [ ] Electron 窗口标题显示为“Rocky的图片工作室”。
- [ ] 输入区不再重复显示“当前 API”和“参数边界：模式”。

## 三、默认保存目录

- [ ] 未手动修改保存目录时，默认目录名称为“Rocky的图片工作室”。
- [ ] 成功生成图片后，文件能保存到该目录。
- [ ] 右键“打开文件夹”能定位到正确目录。

## 四、旧 state.json 迁移

- [ ] 使用旧版无 `threads` 的状态文件启动，应用不白屏。
- [ ] 使用旧版无 `composer` 的线程数据启动，应用能自动补齐默认字段。
- [ ] 使用旧版无 `promptPresets` 的状态启动，提示词库仍可正常打开。
- [ ] 迁移后应用可继续保存状态，不会破坏旧数据。

## 五、两个对话的 composer 隔离

- [ ] 新建两个对话 A / B。
- [ ] 对话 A 和 B 分别输入不同提示词，切换后互不影响。
- [ ] 对话 A 和 B 分别选择不同参数，切换后能正确恢复。
- [ ] 对话 A 添加参考图后，对话 B 不会显示该参考图。
- [ ] 切换线程后，未生成的草稿不会丢失。

## 六、提示词库

### 保存 / 读取 / 去重

- [ ] 可以从当前输入区保存提示词。
- [ ] 保存后，提示词条目会立即出现在提示词库。
- [ ] 读取提示词后，只更新当前对话的提示词内容。
- [ ] 使用相同 `标题 + 提示词` 再次保存时，不会新增重复条目。
- [ ] 连续快速点击保存按钮时，按钮会进入“保存中...”并阻止重复提交。

### 缩略图优先级

- [ ] 当前选中了生成图时，保存的提示词条目使用该生成图做缩略图。
- [ ] 没有选中生成图但有参考图时，保存的提示词条目使用参考图做缩略图。
- [ ] 两者都没有时，提示词条目显示占位图。
- [ ] 重启应用后，提示词库数据仍存在。

## 七、文生图 / 图生图自动判断

- [ ] 无参考图时，发起生成后记录模式为 `text-to-image`。
- [ ] 添加参考图后，发起生成后记录模式为 `image-to-image`。
- [ ] 移除参考图后，模式会恢复为文生图。
- [ ] 比例选项包含 `3:2`、`2:3`、`2:1`。

## 八、图片预览交互

- [ ] 当前图点击预览可打开大图弹窗。
- [ ] 生成记录图点击预览也可打开大图弹窗。
- [ ] 预览弹窗支持放大、缩小。
- [ ] 预览弹窗支持拖拽移动图片。
- [ ] 点击“重置”后，缩放和位置恢复默认。
- [ ] 切换到另一张图时，预览状态会重置。
- [ ] 拖拽后松开鼠标，不会继续保持拖动态。

## 九、API 设置与 mock API 回归

- [ ] API 设置弹窗可以正常打开。
- [ ] 可以新增、编辑并保存 API 配置。
- [ ] 输入非法 URL 时，仍会提示格式错误。
- [ ] 使用 mock API 场景时，文生图 / 图生图的请求链路未回归。
- [ ] 生成失败时，记录会落为 `failed`，界面不会卡死。

## 建议记录方式

每完成一项，建议记录为：

- `通过`
- `失败`
- `需确认`

如果失败，额外记一句：

- 做了什么操作
- 实际看到了什么
- 期望看到什么
