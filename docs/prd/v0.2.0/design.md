# v0.2.0 界面设计文档

> 本版本界面设计目标：将首版“本地生图工作台”升级为更简洁、干净、专注的“Rocky的图片工作室”，减少重复控件和强装饰感，强化提示词复用、独立对话和图片细节查看。

---

## 1. 页面结构概览

### 1.1 页面清单

| 页面 | 功能描述 | 优先级 |
|------|----------|--------|
| 主工作室 | 对话切换、当前图片、提示词输入、参数选择、生成记录 | P0 |
| 提示词库弹窗 | 保存、读取、查看带缩略图的提示词 | P0 |
| API 设置弹窗 | 继续管理 API、模型、能力边界和图片保存目录 | P0 |
| 图片预览弹窗 | 支持生成图和记录图缩放、拖拽、重置视图 | P0 |

### 1.2 主界面布局

主界面继续使用三栏结构，但视觉上更轻，减少厚重卡片。顶部负责全局状态和操作，中间负责当前创作。

```text
┌──────────────────────────────────────────────────────────────────────────────────────┐
│ Rocky的图片工作室                                  API: xxx / model-x  [主题] [设置] │
├────────────────┬──────────────────────────────────────┬──────────────────────────────┤
│ 对话           │ 当前创作                             │ 生成记录                     │
│ [+ 新建]       │ ┌──────────────────────────────────┐ │ ┌─────────┐ ┌─────────┐      │
│                │ │                                  │ │ │ 缩略图   │ │ 缩略图   │      │
│ 对话 A         │ │          当前图片 / 空状态         │ │ └─────────┘ └─────────┘      │
│ 对话 B         │ │                                  │ │ prompt / 参数 / 时间         │
│ 对话 C         │ └──────────────────────────────────┘ │                              │
│                │ 比例 16:9  分辨率 1K  quality medium │ ┌─────────┐ ┌─────────┐      │
│                │ 参考图 [添加/更换]  当前：自动文生图 │ │ 缩略图   │ │ 缩略图   │      │
│                │ ┌──────────────────────────────────┐ │ └─────────┘ └─────────┘      │
│                │ │ 输入提示词...                     │ │                              │
│                │ └──────────────────────────────────┘ │                              │
│                │ [读取提示词] [保存提示词]      [生成] │                              │
└────────────────┴──────────────────────────────────────┴──────────────────────────────┘
```

## 2. 视觉风格

### 2.1 方向

- 参考 Codex / Claude Code 的清爽生产力工具气质。
- 主色克制使用，强调结构、留白、细边框和层级。
- 避免大面积粉色、金色、紫色铺底。
- 图片区域保持中性背景，避免干扰图片颜色判断。

### 2.2 品牌区

- 顶部显示“Rocky的图片工作室”。
- 不显示原来的图标。
- 副标题可弱化或移除，避免占用顶部空间。

### 2.3 信息层级

- 顶部：当前 API、模型、主题、API 设置。
- 中间输入区：提示词、参考图、参数、生成按钮。
- 底部不再重复展示“当前API”和“参数边界：模式”。

## 3. 关键交互设计

### 3.1 每个对话独立状态

**交互说明**：
- 点击左侧对话后，中间区域恢复该对话自己的提示词、参考图和参数。
- 新建对话默认空提示词、无参考图、默认参数。
- 生成记录仍按当前对话显示。

**状态表现**：
- 对话项显示标题、最近提示词摘要、最近状态。
- 当前选中对话使用轻描边或浅底，不使用过强高亮。

### 3.2 提示词库

**入口**：
- 输入框附近提供“读取提示词”和“保存提示词”两个轻量按钮。

**弹窗布局**：

```text
┌──────────────────────────────────────────────┐
│ 提示词库                                  X  │
├──────────────────────────────────────────────┤
│ [搜索/可后置]                                │
│ ┌──────┐  标题：柔和室内摄影                 │
│ │缩略图│  摘要：warm light, clean room...    │
│ └──────┘  [读取] [更新] [删除]               │
│                                              │
│ ┌──────┐  标题：产品海报                     │
│ │占位  │  摘要：minimal poster, studio...    │
│ └──────┘  [读取] [更新] [删除]               │
└──────────────────────────────────────────────┘
```

**保存提示词**：
- 若当前提示词为空，保存按钮不可用或提示先输入提示词。
- 缩略图优先使用当前选中生成图，也允许使用当前参考图。
- 没有图片时也允许保存纯文本提示词。

### 3.3 自动模式

**交互说明**：
- 不再出现“文生图 / 图生图”切换控件。
- 无参考图时显示：“当前：自动文生图”。
- 有参考图时显示：“当前：自动图生图”。
- 添加参考图按钮文案为“添加参考图”；已有参考图时为“更换参考图”。

### 3.4 参数选择器

**显示形态**：

```text
[比例 16:9 ▾] [分辨率 1K ▾] [quality medium ▾]
```

**比例选项**：
- `1:1`
- `4:3`
- `3:4`
- `16:9`
- `9:16`
- `3:2`
- `2:3`
- `2:1`

### 3.5 图片预览弹窗

**布局**：

```text
┌────────────────────────────────────────────────────┐
│ 图片预览              [-] [100%] [+] [重置] [关闭] │
├────────────────────────────────────────────────────┤
│                                                    │
│              可缩放、可拖拽的大图区域              │
│                                                    │
├────────────────────────────────────────────────────┤
│ prompt 摘要 / model / 比例 / 分辨率 / quality       │
└────────────────────────────────────────────────────┘
```

**交互要求**：
- 放大后按住鼠标拖动图片。
- 点击重置恢复默认缩放和位置。
- 关闭弹窗后清空本次缩放和拖拽状态。

## 4. 组件清单

| 组件 | 类型 | 说明 |
|------|------|------|
| `Workspace` | 既有组件改造 | 顶部品牌、三栏布局、全局状态承载 |
| `PromptComposer` | 既有组件改造 | 独立对话输入、自动模式、参数选择器、提示词入口 |
| `PromptLibraryDialog` | 新增组件 | 提示词保存、读取、缩略图展示 |
| `ImagePreviewDialog` | 既有组件改造 | 缩放、拖拽、重置 |
| `PreviewGallery` | 既有组件改造 | 生成记录继续接入可缩放预览 |
| `GenerationCanvas` | 既有组件改造 | 当前图接入可缩放预览 |

## 5. 响应式与窗口适配

| 场景 | 要求 |
|------|------|
| 常规桌面宽度 | 保持三栏结构，参数控件一行展示 |
| 较窄窗口 | 参数控件允许换行，但不遮挡输入框和生成按钮 |
| 图片预览弹窗 | 预览区域随窗口缩放，大图保持居中 |
| 生成记录较多 | 右侧记录区域滚动，顶部和输入区保持可用 |
